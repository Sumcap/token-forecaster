Token Forecaster for claude.ai

The chip shows an estimate of the input you are about to send and a forecast of the reply length. Everything is computed in your browser. It runs on claude.ai/code, which is the surface the shipped profile was fitted on.

Display

Forecast inputs

Verified input count (optional)

Off by default. With it on, and only then, the draft text and the model id go to Anthropic's count_tokens endpoint to replace the local estimate with an exact count. The conversation is never sent. The key is stored unencrypted in extension storage.

Data contribution (optional)

Forecasting works completely without telemetry. These are separate, off-by-default choices. No prompt text, reply text, URL, Claude account information, cookie, or API key is collected. See the full packaged privacy notice.
