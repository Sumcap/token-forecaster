`github-agent-chats` is the flat prompt→reply corpus the semantic probes of
`docs/SEMANTIC-PLAN.md` were graded on. `aider`, `claude-code`, `cline`,
`cline-task`, `codex` and `specstory` are the per-call Tier A sources and
`agent-sessions` is those six pooled — the same underlying files as the flat
corpus, plus the three new formats, cut into calls instead of pairs. Counting
both rows twice would double-count; the base is fitted on `agent-sessions`.

Three columns are declared per source rather than measured, because they are
properties of the format:

- **loop** — the source records more than one model call per human turn.
- **cycle** — a session holds several human turns in sequence.
- **timestamps** — the EMITTED rows carry a wall clock. False for every public
  source even where the underlying file has one (Claude Code and Codex
  transcripts do), because the harvester deliberately does not emit it.

`swebench-trajs` is the Tier B smoke pull, two submissions of sixty tasks each,
not the full set. `wildchat` is Tier C: the source conversations are multi-turn,
but the slice that was built keeps only the first turn of each, so turns per
session is 1 until the multi-turn extraction is done.

### What the census says

1. **The loop is now visible on public data.** The flat corpus reads as one call
   per turn on 86% of rows, which is a rendering artifact of aider and Cursor
   exports. On `claude-code`, `cline-task` and `codex` the median turn is 3 calls
   with a p90 of 15 to 19 — the shape the local corpus has at 7 and 37, one
   scale down.
2. **Native labels are still the minority.** 19% of Tier A calls and 12% of Tier
   A turns carry an output-token count the provider wrote. Everything else is a
   tiktoken count of visible text, flagged `visible_text_only`, and is a floor.
3. **Users, not turns, are the binding constraint on the stranger gate.** Tier A
   has 1,693 repositories, but only 93 with 20 or more sessions and only 30 of
   those on `claude-code`. Turn volume is no longer the problem; user count is.
4. **Tier B does not carry the per-step tokens the plan assumed.** See below.

## Fold rules

**Public data: leave-user-out and leave-source-out. Never chronological.**

- The fold key is the **user**: `owner/repo` for every Tier A source, the
  submission for Tier B, the submitter's hashed IP for WildChat. A user's rows
  are never split across a fold boundary.
- The second fold is **leave-source-out**: hold out `claude-code` entirely, fit
  on the rest, and grade. That is the only test of whether a base trained mostly
  on rendered markdown transfers to a real agent loop.
- **No chronological fold on public data, ever.** The public rows carry no wall
  clock; `firstMs` in the flat corpus is harvest order, and this corpus emits no
  timestamp at all. A "chronological" split on them would be a split on search
  result order dressed up as time.
- **The local corpus keeps its chronological session folds**, and stays the
  realism target: `docs/PLAN-OF-ATTACK.md` "Risks, named" forbids public rows
  from entering a holdout that claims realism.

## Tier B: access status

**The bucket is readable without credentials. The data is not what the plan
assumed.**

| | |
|---|---|
| Bucket | `s3://swe-bench-submissions` |
| Credentials | **none needed.** `--no-sign-request` reads objects and lists non-empty prefixes |
| Root listing | denied — `aws s3 ls s3://swe-bench-submissions/ --no-sign-request` returns `AccessDenied` |
| Consequence | keys are BUILT from each submission's `metadata.yaml` (`assets.trajs`), never discovered by listing |
| Key layout | `<prefix>/<submission>/trajs/<instance>/<instance>.traj.json`, and a flat `<prefix>/<submission>/trajs/<instance>.traj.json` for some submissions |
| mini-SWE-agent submissions | **62** of 326 scanned (48 verified, 14 multilingual), 47 distinct models |

The plan's Tier B was to give ~30,000 trajectories with `completion_tokens`
split into reasoning and text. One trajectory was probed from each of the 62
submissions:

| trajectory format | submissions | per-step usage |
|---|---|---|
| `mini-swe-agent-1.1`, OpenAI Responses objects | 3 | **yes** — `usage.output_tokens` and `usage.output_tokens_details.reasoning_tokens` per step |
| `mini-swe-agent-1.1`, LiteLLM-normalised messages | 10 | no, but reasoning TEXT is present |
| `mini-swe-agent-1` | 18 | no |
| legacy `{role, content}` | 7 | no |
| `assets.trajs` declared but the prefix is empty | 16 | – |
| instance directory holds logs and a patch but no `.traj.json` | 6 | – |
| trajectories hosted on GitHub, not S3 | 2 | – |

So Tier B answers the **loop-dynamics prior** from every downloadable
submission, and the **re-forecast-at-k** and **thinking-ratio** questions from
three submissions only. The smoke pull took 60 tasks from one submission of each
era: 3,239 steps over 120 tasks, of which 1,940 carry true per-step usage.
Median reasoning share of output tokens on those, **0.416**. Loop length, median
23 steps per task, p90 49, max 73 — and mini-SWE-agent caps its own step count,
so the tail is censored and the prior has to be fitted as a survival curve.

Details, including what each of the 62 submissions turned out to be, are in
`experiments/datasets/public/swebench-trajs/MANIFEST.md`.

## The privacy rule, restated

Every harvested file carries other people's prompt text. `calls.jsonl`,
`turns.jsonl`, `steps.jsonl` and `raw/` are gitignored under
`experiments/datasets/public/*/*`; only each dataset's `MANIFEST.md` is
committed. Prompt text is research input: it is never committed, never printed
in a report, never pasted into a document, and never redistributed. The census
script reads those files and emits counts; `export-turn-text.mjs` and
`census.py --local` both refuse a path inside the repository.
